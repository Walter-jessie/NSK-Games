# NSK Games 🏭

**Interactive Mobile Training Portal for NSK Bearings, Chennai Plant**

A gamified PWA training suite where employees across all departments compete in bearing-themed interactive games to test and enhance their plant knowledge.

## Included Games & Features

- 🎮 **Game 1: Bearing Runner** — 2.5D lane runner quiz game with 450+ NSK official questions across 9 plant departments
- 🔧 **Game 2: Plant Arena Repair** — 3D interactive factory arena repair challenge
- 🏆 **Live Leaderboard** — Real-time plant-wide scoreboard via Supabase cloud
- 🔍 **Bearing Check 3D** — Interactive 3D bearing inspection, rotation & diagnostics
- 📱 **PWA & Mobile-First** — Installable on Android/iOS, landscape-optimized with AAA fullscreen recovery
- ⚡ **60 FPS** — GPU-accelerated rendering and Three.js 3D pipelines

## Tech Stack

- React 18 + Vite
- Three.js (3D Graphics)
- Tailwind CSS
- Supabase (Realtime DB)

## Getting Started

```bash
npm install
npm run dev
```
